# Współpraca agentów

Repozytorium jest wspólnym obszarem pracy agentów Codex i Claude. Zmiany jednej strony są od razu widoczne dla drugiej, dlatego przed edycją należy sprawdzić `git status --short`, a po edycji zweryfikować tylko własny zakres.

Nie cofaj ani nie formatuj masowo cudzych zmian. Jeśli dwa zadania muszą zmienić ten sam plik, zachowaj aktualną zawartość i dopisz zmianę możliwie małym patchem.

`AGENTS.md` jest krótkim indeksem spraw, a pliki w `index/` zawierają wiedzę potrzebną do dalszej pracy.
